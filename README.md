## 1. Введение

**«Оперный Певец»** — 2D-платформер, в котором вы играете за оперного певца,
сражающегося с врагами силой собственного голоса. Вместо оружия вы используете
**музыкальные ноты**, высота которых зависит от того, как долго удерживается
клавиша пения.

### Ключевые особенности

| Особенность | Описание |
|---|---|
| 🎤 **Пение вместо стрельбы** | Удерживайте ENTER — нота «плывёт» по диапазону голоса |
| 🎭 **3 типа голоса** | Тенор, Бас, Баритон — у каждого свой диапазон и характер урона |
| 🌍 **21 опера** | От «Руслана и Людмилы» до «Валькирии» |
| 👹 **21 уникальный враг** | Свой тип врага для каждой оперы |
| 🎼 **12 арий** | 4 арии на каждый голос, активируются кликом по персонажу |
| 💾 **Сохранение** | Сохранение и загрузка прогресса этапа в файл `.song` |
| 🎬 **Оперные занавесы** | Анимированное меню паузы и главное меню |

## 2. Быстрый старт

### Пошаговая инструкция

1. Откройте HTML-файл в браузере (Chrome, Firefox, Edge, Safari).
2. В главном меню выберите **тип голоса**: Тенор, Бас или Баритон.
3. Дождитесь загрузки сцены — вы появитесь на стартовой платформе.
4. Управляйте певцом стрелками / A-D, прыгайте SPACE.
5. Удерживайте **ENTER** для набора высоты ноты, отпустите — выстрел.
6. Собирайте ♪ и ♫ для очков, убивайте врагов и выполняйте задачи этапа.
7. Кликните **по персонажу** — откроется меню арий (спецспособности).

### Первые 30 секунд
Меню → Выбор голоса → Сцена → [← →] движение → [SPACE] прыжок
↓
[ENTER] удерживать = пение
↓
отпустить = выстрел нотой

## 3. Управление

### Основные клавиши

| Действие | Клавиши |
|---|---|
| **Движение влево** | ← или A (или Ф) |
| **Движение вправо** | → или D (или В) |
| **Прыжок** | SPACE, ↑, W или Ц |
| **Пение (набор высоты)** | Удерживать ENTER |
| **Выстрел нотой** | Отпустить ENTER |
| **Меню арий** | ЛКМ по персонажу |
| **Пауза** | P, З или ESC |
| **Закрыть меню арий** | ESC или клик по фону |
| **Перезапуск** | F5 |

### Двойной прыжок

Работает только при активной арии **«Ария Фигаро»** (Баритон).
В воздухе нажмите SPACE ещё раз — персонаж совершит второй прыжок.

### Мышь

- **Курсор** — кастомный (`cur.png`), меняется на всех интерактивных элементах.
- **Клик по певцу** — открывает меню арий (только во время игры).
- **Клик по фону меню арий** — закрывает меню.

## 4. Типы голосов

Три голоса отличаются **диапазоном**, **кривой урона** и **внешним видом**.

### 🎭 Тенор

| Параметр | Значение |
|---|---|
| Диапазон | **C3 – C5** (MIDI 48–72) |
| Урон | Растёт с высотой ноты |
| Сила | Высокие ноты наносят огромный урон |
| Слабость | Низкие ноты почти бесполезны |
| Внешность | Красный камзол, белое жабо, тёмные волосы |
| Стиль | Агрессивный, «убийца сверху» |

**Формула урона:** `damage = 1.6 × (0.4 + t × 1.6) × 20`
где `t` — нормированная высота (0 = низ, 1 = верх).

### 🎭 Бас

| Параметр | Значение |
|---|---|
| Диапазон | **E2 – E4** (MIDI 40–64) |
| Урон | Падает с высотой ноты |
| Сила | Низкие ноты наносят максимальный урон |
| Слабость | Высокие ноты слабы |
| Внешность | Чёрный камзол, седая борода, большой живот |
| Стиль | Танк, «тяжёлая артиллерия» |

**Формула урона:** `damage = 1.0 × (2.0 − t × 1.6) × 20`

### 🎭 Баритон

| Параметр | Значение |
|---|---|
| Диапазон | **A2 – A4** (MIDI 45–69) |
| Урон | Максимум в **середине** диапазона |
| Сила | Сбалансирован, стабилен |
| Слабость | Края диапазона слабее |
| Внешность | Смокинг, цилиндр, пенсне, трость |
| Стиль | Универсал, «джентльмен» |

**Формула урона:** `damage = 1.3 × (0.6 + 1.4 × (1 − |t − 0.5| × 2)) × 20`

### Сравнительная таблица

| Голос | Мин. нота | Макс. нота | Лучшая зона | Урон в лучшей зоне |
|---|---|---|---|---|
| Тенор | C3 | C5 | C5 (верх) | ~64 |
| Бас | E2 | E4 | E2 (низ) | ~64 |
| Баритон | A2 | A4 | D3–D4 (центр) | ~52 |

## 5. Механика пения и нот

### Как это работает

1. **Нажатие ENTER** — начинается заряд. `chargeValue` растёт от 0 до 1.
2. **Достигнув 1** — значение идёт обратно к 0 (пинг-понг).
3. **Отпускание ENTER** — выстрел нотой, соответствующей текущему `chargeValue`.

### Отображение

- **HUD (слева вверху)** — текущая нота (например, `C4`), цветной индикатор.
- **Полоса заряда** — заполняется синхронно с `chargeValue`.
- **Частицы** — при пении вокруг певца летят нотные искры.

### Формула ноты
midi = minMidi + round(chargeValue × (maxMidi − minMidi))

Например, для тенора при `chargeValue = 0.5`:
`midi = 48 + round(0.5 × 24) = 60 = C4`

### Урон ноты
damage = damageBase × damageCurve(t) × 20

При активной арии **«Ярость»** (`rage`) урон **умножается на 2**.

### Задержка между выстрелами

`shotCooldown = 0.35 сек` — нельзя стрелять чаще, чем раз в 0.35 секунды.

### Цвет ноты

Цвет плавно переходит:
- от `low` → `mid` при `t < 0.5`
- от `mid` → `top` при `t ≥ 0.5`

У каждого голоса свои три цвета.

## 6. Типы этапов

Каждая опера состоит из **3 этапов**, каждый — одного из трёх типов.

### 🎯 Этап «kill» (убийство)

| Параметр | Значение |
|---|---|
| Цель | Убить N врагов |
| Прогресс | `enemiesKilled / enemiesTotal` |
| Враги | Генерируются на платформах |
| Ширина | 3800–4600+ px |

### 🎵 Этап «collect» (сбор)

| Параметр | Значение |
|---|---|
| Цель | Собрать N нот |
| Прогресс | `notesCollected / notesNeeded` |
| Ноты | ♪ (1 очко) и ♫ (5 очков) |
| Ширина | 3800–4600+ px |

### 👹 Этап «boss» (босс)

| Параметр | Значение |
|---|---|
| Цель | Убить босса |
| Прогресс | HP босса |
| Босс | Уникален для каждой оперы |
| Ширина | 2400 px |

### Масштабирование

Цели этапов умножаются на `1 + operaIdx × 0.03`:
- Опера 1 (индекс 0): ×1.00
- Опера 21 (индекс 20): ×1.60

### Прохождение этапа

После выполнения цели показывается оверлей:
- **Этапы 1–2** → кнопка «ДАЛЕЕ» → следующий этап.
- **Этап 3** → конец оперы → следующая опера (или финал).

## 7. Система арий

### Как открыть меню арий

1. Убедитесь, что игра активна (не пауза, не оверлей).
2. **Кликните ЛКМ по персонажу** (по его спрайту).
3. Откроется меню с 4 ариями вашего голоса.

### Интерфейс меню арий
┌─────────────────────────────────────────┐
│ 🎭 Арии — Тенор │
│ Очки: 𝄞1250 • Кликните по арии │
├─────────────────────────────────────────┤
│ ┌──────────────┐ ┌──────────────┐ │
│ │ ❄️ Ария │ │ 💚 Серенада │ │
│ │ Ленского │ │ │ │
│ │ Заморозка │ │ +1 здоровье │ │
│ │ 𝄞 150 ⏱12с │ │ 𝄞 100 ⏱15с │ │
│ └──────────────┘ └──────────────┘ │
│ ┌──────────────┐ ┌──────────────┐ │
│ │ 🎯 Vincerò! │ │ ⏳ Романс │ │
│ │ Залп 5 нот │ │ Замедление │ │
│ │ 𝄞 120 ⏱10с │ │ 𝄞 180 ⏱18с │ │
│ └──────────────┘ └──────────────┘ │
└─────────────────────────────────────────┘

### Правила активации

- Стоимость списывается из очков (`score`).
- Если очков не хватает — карточка **неактивна** (тусклая).
- Если ария на кулдауне — карточка **неактивна** (показывает ⏱).
- После активации меню **автоматически закрывается**.

### Кулдаун

Каждая ария имеет свой кулдаун. Отсчёт идёт **в реальном времени** игры.
Индикатор кулдауна виден в меню арий.

### Описание эффектов

- **freeze** — все враги замирают, покрываются льдом.
- **heal** — восстанавливает 1 ❤️ (максимум 5).
- **volley** — 5 нот летят веером (углы −0.6…+0.6 рад).
- **slow** — `timeScale = 0.4`, всё движется медленнее.
- **invuln** — певец не получает урона.
- **shield** — поглощает 1 удар, потом исчезает.
- **explosion** — 150 урона всем врагам на экране.
- **killAll** — мгновенно убивает всех врагов (120 урона боссу).
- **doubleJump** — SPACE в воздухе → второй прыжок.
- **magnet** — ноты летят к игроку.
- **push** — враги отлетают от игрока.
- **rage** — урон ×2.

### Индикаторы активных эффектов

В правом верхнем углу появляются **бейджи**:
┌─────────────────────┐
│ ⚔️ Ярость x2 6с │
│ 🛡️ Неуязвимость 3с │
└─────────────────────┘

Бейджи пульсируют золотым свечением.

## 10. Боссы

### Общие характеристики

- **HP:** `800 + operaIdx × 110`
- **Размер:** `130 × 180 px`
- **Позиция:** ближе к концу этапа
- **Атаки:** стреляет снарядами в игрока
- **Движение:** плавно смещается вбок

### Поведение босса

1. **Патрулирование** — синусоидальное движение вбок.
2. **Стрельба** — каждые `1.6–2.8 сек` выпускает снаряд в игрока.
3. **Снаряды** — летят со скоростью 6, живут 3 сек.
4. **Контактный урон** — при касании наносит 1 урон.

### Уязвимость

- Урон от нот обычный.
- **Реквием** (Бас) снимает 120 HP.
- **Взрыв** (Бас) снимает 90 HP.

### HP bar

Над боссом отображается полоса HP:
┌──────────────────────────────────┐
│ Черномор — 542 HP │
│ ████████████████░░░░░░░░░░░░░░ │
└──────────────────────────────────┘

Градиент: красный → оранжевый → красный.

### Поражение на этапе босса

Если вы умираете на этапе босса — **игра заканчивается** (game over).
На обычных этапах — возрождение с 3 ❤️.

## 12. Собираемые ноты

### Типы нот

| Символ | Тип | Очки | Цвет | Размер |
|---|---|---|---|---|
| ♪ | single | +1 | `#ffd700` | 28px |
| ♫ | double | +5 | `#ff8c00` | 34px |

### Появление

- Ноты размещаются **на платформах** (кроме земли).
- 75% — ♪, 25% — ♫.
- Если платформ не хватает — ноты падают на землю.

### Анимация

- Ноты **покачиваются** (`bob += 0.06`).
- Свечение (shadowBlur = 15).
- При подборе — **взрыв частиц** и всплывающий текст `+N`.

### Магнит (ария Баритона)

Ария **«Серенада Дон Жуана»** включает магнит:
- Все ноты в радиусе экрана притягиваются к игроку.
- Скорость притяжения: 12 px/кадр.

### Счётчик

- **HUD:** `𝄞N` — общий счёт.
- **Objective HUD:** `notesCollected / notesNeeded`.

## 13. Здоровье и урон

### Здоровье

- Стартовое: **3 ❤️**
- Максимум: **5 ❤️** (после арий лечения)
- Отображение: `❤️❤️❤️` в HUD

### Получение урона

1. **Касание врага** — 1 ❤️, отброс, 1.5 сек неуязвимости.
2. **Снаряд босса** — 1 ❤️, отброс, 1.5 сек неуязвимости.
3. **Касание босса** — 1 ❤️, отброс.

### Неуязвимость

- После урона: **1.5 сек** (мигание спрайта).
- При старте этапа: **1.0 сек**.
- Ария «Песня Варлаама»: **5 сек**.

### Щит

- Поглощает **1 удар**.
- Исчезает после поглощения.
- Визуально — синий круг вокруг певца.

### Смерть

- При 0 ❤️ запускается `deathTimer = 2 сек`.
- **Обычный этап** → возрождение с 3 ❤️ через 2 сек.
- **Этап босса** → Game Over.

### Game Over

💀
ПОРАЖЕНИЕ

## 15. Сохранение и загрузка

### Сохранение

1. Нажмите **P** или **ESC** → откроется меню паузы.
2. Нажмите **💾 СОХРАНИТЬ УРОВЕНЬ**.
3. Файл `.song` скачается автоматически.
4. Имя файла: `opera_save_<название>_stage<N>.song`.

### Что сохраняется

|---|---|
| `version` | Версия формата (1) |

| `operaIdx` | Индекс оперы |
| `stageIdx` | Индекс этапа |
| `health` | Здоровье |
| `score` | Очки |
| `time` | Время |
| `player` | Позиция, скорость, направление |

## 18. Стратегии и советы

### Общие советы

1. **Не стреляйте вслепую** — ждите удобного момента.
2. **Используйте всю высоту** — платформы дают преимущество.
3. **Следите за зарядом** — для тенора ждите пика, для баса — низа.
4. **Комбинируйте арии** — например, «Ярость» + «Vincerò!».
5. **Экономьте очки** — дорогие арии оставьте на босса.

### Стратегия для Тенора

- Держите ENTER долго — стреляйте на пике.
- «Vincerò!» — против группы врагов.
- «Ария Ленского» — против толпы.
- «Романс» — для сбора нот под огнём.

### Стратегия для Баса

- Стреляйте на низких нотах — максимальный урон.
- «Реквием» — экстренная кнопка на боссе.
- «Песня Варлаама» — для прохода сквозь толпу.
- «Ария Бориса» — щит на боссе.

### Стратегия для Баритона

- Стреляйте в среднем диапазоне (D3–D4).
- «Ария Фигаро» — для вертикального маневрирования.
- «Серенада Дон Жуана» — для сбора нот.
- «Песня Тореадора» — для босса.

### Против босса

1. Держитесь на средней дистанции.
2. Уклоняйтесь от снарядов (они летят по прямой).
3. Стреляйте в момент перезарядки босса.
4. Активируйте «Ярость» или «Реквием» в начале боя.

## 20. Решение проблем

### Нет звука

- **Причина:** Браузер блокирует автовоспроизведение.
- **Решение:** Кликните по экрану или нажмите любую клавишу.

### Музыка не играет

- **Причина:** Файл `music.mp3` отсутствует.
- **Решение:** Добавьте `music.mp3` в папку с игрой.

### Курсор не отображается

- **Причина:** Файл `cur.png` отсутствует.
- **Решение:** Добавьте `cur.png` в папку с игрой.

### Игра тормозит

- **Причина:** Много частиц на экране.
- **Решение:** Уменьшите количество врагов или закройте другие вкладки.

### Сохранение не работает

- **Причина:** Браузер блокирует скачивание.
- **Решение:** Разрешите скачивание файлов для этого сайта.

### Загрузка не работает

- **Причина:** Повреждённый файл `.song`.
- **Решение:** Проверьте JSON-формат файла.

### Не открывается меню арий

- **Причина:** Клик не по персонажу.
- **Решение:** Кликните точно по спрайту певца.

### Босс не умирает

- **Причина:** У босса большой HP.
- **Решение:** Используйте «Реквием» или «Взрыв».

### Персонаж застревает

- **Причина:** Баг генерации платформ.
- **Решение:** Прыгните или перезапустите этап.

### Ошибка декодирования аудио

- **Причина:** Повреждённая base64-строка.
- **Решение:** Игра автоматически переключится на синтез.
