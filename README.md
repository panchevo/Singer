## Введение

**«Оперный Певец»** — 2D-платформер, в котором вы играете за оперного певца,
сражающегося с врагами силой своего голоса.

**Ключевые особенности:**

- 🎵 Музыкальный геймплей — стрельба нотами с заряжаемой высотой тона
- 🎭 21 опера с уникальными боссами, врагами и визуальными темами
- 📈 RPG-элементы — уровни, характеристики, разблокировка арий
- 🎼 Реалистичный синтез голоса — форманты, вибрато, дыхание

**Цель:** пройти все 21 оперу (по 3 этапа в каждой), победив финального босса.

## Управление

| Клавиша | Действие |
|---------|----------|

| `→` / `D` / `В` | Движение вправо |
| `↑` / `W` / `Ц` / `Space` | Прыжок |
| `Enter` (удерживать) | Зарядка ноты |
| `Enter` (отпустить) | Выстрел нотой |
| `1`–`7` | Активация арии из слота |
| `P` / `З` | Пауза |
| `Esc` | Закрыть меню / Пауза |
| `Space` / `Enter` | Продолжить диалог |
| `Esc` | Пропустить диалог |

### 🖱️ Мышь

| Действие | Эффект |
|----------|--------|
| **Движение** | Прицеливание (игрок и нота смотрят на курсор) |
| **ЛКМ** (удерживать) | Зарядка ноты |
| **ЛКМ** (отпустить) | Выстрел |

### 🎯 Механика прицеливания

Направление полёта ноты определяется **положением курсора мыши** относительно игрока.
Спрайт певца автоматически разворачивается в сторону курсора.

- Нота летит по прямой в сторону курсора с небольшим подъёмом (дуга)
- Угол выстрела: от игрока к курсору
- Скорость зависит от силы зарядки и типа голоса

При старте игры вы выбираете один из трёх типов голоса.
**Выбор необратим в текущей сессии!**

### 🎩 Тенор

|----------|----------|

| **Урон** | 1.6 (высокий) |
| **Скорость снаряда** | ×1.00 |
| **Особенность** | Максимальный урон в верхнем регистре |

Хорош для агрессивного стиля.

| Параметр | Значение |
|----------|----------|
| **Диапазон** | E2 – E4 (MIDI 40–64) |

| **Цвета нот** | Низ: `#ffd700` → Середина: `#ff8c00` → Верх: `#8b4513` |

**Стратегия:** не заряжайте до конца — стреляйте на низкой зарядке (0–0.4).

### 🎭 Баритон

| Параметр | Значение |
|----------|----------|
| **Диапазон** | A2 – A4 (MIDI 45–69) |

| **Скорость снаряда** | ×0.95 |
| **Особенность** | Пик урона в среднем регистре (~0.4 зарядки) |
| **Цвета нот** | Низ: `#ff8c00` → Середина: `#ffd700` → Верх: `#c0392b` |

**Стратегия:** идеален для универсального стиля.
Держите зарядку около 40% для оптимального урона.

## Основы геймплея

### 🎵 Стрельба нотами

1. **Зажмите ЛКМ или Enter** — начнётся зарядка
2. **Индикатор заряда** (полоса в HUD) колеблется от 0% до 100%
3. **Нота определяется** по текущей высоте тона (C3, D#4, A5 и т.д.)
4. **Отпустите** — нота вылетает в сторону курсора

**Формула урона:**

    damage = voice.damageBase × voice.damageCurve(t) × 20 × levelPowerMul × rageMul

где `t` — уровень зарядки (0–1).

### ❤️ Здоровье

- Начальное здоровье: **3 сердца**
- При столкновении с врагом/снарядом: **−1 HP**
- После урона: **1.5 сек неуязвимости** (мигание)
- При 0 HP:
  - На обычном этапе: возрождение через 2 секунды
  - На этапе босса: **поражение** → возврат к предыдущему этапу

### 📊 HUD (верхний левый угол)

| Элемент | Значение |
|---------|----------|
| Название ноты | Текущая высота тона |
| Полоса заряда | Уровень зарядки (0–100%) |
| Тип голоса | Название и описание |
| Сердечки | Текущее здоровье |
| 🎼 Счёт | Очки (валюта для арий) |

### 🎯 Objective HUD (верхний центр)

Показывает:
- Название и композитора оперы
- Номер этапа (1/3) и его цель
- Прогресс: убито врагов / собрано нот

### ✨ Индикаторы эффектов (верхний правый)

Показывают активные эффекты арий с обратным отсчётом.

## Система опыта и уровней

### 📈 Формула опыта

    XP для уровня L = 100 + (L − 1) × 50

- Ур. 1 → 2: 100 XP
- Ур. 2 → 3: 150 XP
- Ур. 3 → 4: 200 XP
- ...
- **Максимальный уровень: 10**

### 💎 Источники опыта

| Действие | XP |
|----------|-----|
| Убийство врага | +40 |
| Сбор одиночной ноты | +5 |
| Сбор двойной ноты | +15 |
| Прохождение этапа | +50 |
| Убийство босса | +200 |

### 🎁 Награды за уровень

При каждом повышении уровня вы получаете **+1 очко характеристик**.

## Характеристики

Откройте панель, кликнув на **бейдж уровня** внизу слева.

### 📊 Список характеристик

| Характеристика | Эффект за 1 очко | Формула |
|----------------|------------------|---------|
| **Мощь голоса** | +8% урона | `1 + power × 0.08` |
| **Дальность** | +10% скорости полёта ноты | `1 + range × 0.10` |
| **Фразировка** | −5% перезарядки выстрела (мин. 0.5) | `max(0.5, 1 − phrase × 0.05)` |
| **Артистизм** | +10% длительности эффектов арий | `1 + art × 0.10` |
| **Исполнительность** | −6% стоимости арий (мин. 0.4) | `max(0.4, 1 − perf × 0.06)` |

### 💡 Рекомендации по прокачке

- **Агрессивный стиль:** Мощь → Фразировка → Дальность
- **Стиль арий:** Артистизм → Исполнительность → Мощь
- **Универсал:** Мощь → Артистизм → Фразировка

## Боссы

Каждый босс уникален по визуалу и поведению.

### 🎨 Особенности боссов

- **HP бар** вверху экрана (с делениями по 10%)
- **Уникальный внешний вид** (рисованный через Canvas API)
- **Аура** — пульсирующее свечение в цвете босса
- **Анимация** — дыхание, покачивание, мигание при уроне
- **Атака** — стреляют снарядами в игрока

### ⚔️ Механика боя

1. **Уклоняйтесь** от снарядов босса
2. **Стреляйте нотами** — каждая нота наносит урон
3. **Урон от столкновения** с боссом — −1 HP
4. **Победа** — HP босса = 0

### 💡 Совет

Перед атакой босса есть **пауза** — используйте это время для перезарядки.

## Типы этапов

В каждой опере три типа этапов (в разном порядке):

### 🎯 1. Kill — уничтожение врагов

- **Цель:** убить N врагов (5–12 в зависимости от оперы)
- **Враги:** появляются на платформах
- **Прогресс:** счётчик убитых / всего

### 🎵 2. Collect — сбор нот

- **Цель:** собрать N нот (8–18 в зависимости от оперы)
- **Ноты:**
  - Одиночная (`♪`) — 1 очко, +5 XP
  - Двойная (`♫`) — 5 очков, +15 XP
- **Прогресс:** счётчик собранных / всего

### 👹 3. Boss — битва с боссом

- **Цель:** победить босса оперы
- **Босс:** уникальный для каждой оперы
- **Возврат:** при смерти — на предыдущий этап

## Сохранение и загрузка

### 💾 Сохранение

1. Нажмите `P` или `Esc` — откроется меню паузы
2. Нажмите **«СОХРАНИТЬ УРОВЕНЬ»**
3. Скачается файл `opera_save_<Опера>_stage<N>.song`

**Что сохраняется:**
- Тип голоса, текущая опера и этап
- Здоровье, счёт, время
- Уровень, XP, очки характеристик
- Позиция игрока и камеры
- Платформы, враги, босс
- Собираемые ноты
- Активные эффекты и кулдауны

### 📂 Загрузка

1. Откройте меню паузы (`P` / `Esc`)
2. Нажмите **«ЗАГРУЗИТЬ УРОВЕНЬ»**
3. Выберите файл `.song`

### ⚠️ Важно

- Загрузка **заменяет** текущую игру
- Формат файла — JSON с версией
- При несовпадении версии — ошибка

## Стратегии и советы

### 🎯 Базовые советы

1. **Прицеливайтесь мышью** — нота летит в сторону курсора
2. **Учитесь таймингу** — отпускайте ЛКМ в нужный момент зарядки
3. **Экономьте HP** — на этапе босса смерть = откат этапа
4. **Собирайте ноты** — они дают очки для арий
5. **Прокачивайте характеристики** — открывайте панель кликом на бейдж

### 🎩 Советы для Тенора

- Заряжайте до максимума — урон максимален
- Арии для агрессии: Калаф + Юродивый
- Держите дистанцию — вы хрупкий

### 🐻 Советы для Баса

- Стреляйте на низкой зарядке — урон максимален
- Варлаам + Борис — для выживания
- Телепорт — для уклонения

### 🎭 Советы для Баритона

- Держите зарядку ~40% — оптимальный урон
- Фигаро + Тореадор — для агрессии
- Двойной прыжок — для мобильности

### 🥊 Тактика против боссов

1. **Держите среднюю дистанцию** — не вплотную, не слишком далеко
2. **Стреляйте в прыжке** — снаряды летят в стороны
3. **Используйте щит/неуязвимость** перед атакой
4. **Следите за снарядами** — они летят по прямой в вашу сторону

### 💎 Экономика очков

- Очки = валюта для арий
- Не тратьте всё — оставьте на экстренный случай
- Исполнительность снижает стоимость — вкладывайтесь

## FAQ

### ❓ Как открыть меню арий?

**Ответ:** Кликните по игроку (по персонажу) ЛКМ.

### ❓ Как активировать арию?

**Ответ:** Нажмите цифру `1`–`7` или кликните по слоту внизу экрана.

### ❓ Почему ария заблокирована?

**Ответ:** Не хватает уровня персонажа (см. колонку «Ур.» в таблице арий).

### ❓ Как повысить уровень?

**Ответ:** Собирайте опыт: убивайте врагов, собирайте ноты, проходите этапы.

### ❓ Что делать, если закончились очки?

**Ответ:** Собирайте ноты и убивайте врагов — они дают очки.

### ❓ Можно ли сменить голос?

**Ответ:** Только начав новую игру (перезагрузка страницы).

### ❓ Как пройти этап с боссом?

**Ответ:** Уклоняйтесь от снарядов, стреляйте нотами, используйте арии.

### ❓ Почему нота не убивает врага?

**Ответ:** Нота наносит урон, зависящий от зарядки. У некоторых врагов много HP.
Заряжайте дольше (для тенора/баритона) или стреляйте быстрее (для баса).

### ❓ Как сохранить прогресс?

**Ответ:** `P` → «СОХРАНИТЬ УРОВЕНЬ» → скачается файл `.song`.

### ❓ Можно ли играть без звука?

**Ответ:** Да, звук не влияет на геймплей, но добавляет атмосферы.

### ❓ Что такое «Невесомость»?

**Ответ:** Эффект арии Кармен — низкая гравитация + тройной прыжок на 12 с.

### ❓ Как работает «Откат времени»?

**Ответ:** Поминальная ария баса — возвращает игрока на позицию 3 секунды назад
(из истории позиций) + даёт 1.5 с неуязвимости.
