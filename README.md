## Введение

**«Оперный Певец»** — 2D-платформер, в котором вы играете за оперного
певца и сражаетесь с силами зла при помощи своего голоса. Вместо
оружия — вокальные ноты, вместо патронов — дыхание и артистизм.

Игра включает **21 оперу** мирового репертуара, каждая из которых
состоит из **3 этапов** и завершается битвой с боссом.

**Ключевые особенности:**

- 🎤 Реалистичная имитация вокального синтеза (тенор, бас, баритон)
- 🎼 Уникальная боевая система на основе зарядки нот
- 🎭 21 опера с индивидуальным визуальным стилем
- 👹 21 уникальный тип врага + 21 уникальный босс
- 🎵 12 арий с разными эффектами
- 📈 Система прокачки персонажа через XP

## Быстрый старт

1. Откройте игру в браузере (Chrome / Edge / Firefox).
2. На стартовом экране выберите **тип голоса**:
   - **Тенор** — сбалансированный
   - **Бас** — мощный, но медленный
   - **Баритон** — универсальный
3. Кликните мышью по певцу → откроется **меню арий**.
4. Уничтожайте врагов нотами, собирайте ноты и побеждайте боссов.
5. Пройдите 3 этапа подряд, чтобы перейти к следующей опере.

## Управление

| Действие              | Клавиша                              |
|-----------------------|--------------------------------------|
| Движение влево        | `←` / `A` / `Ф`                      |
| Движение вправо       | `→` / `D` / `В`                      |
| Прыжок                | `Space` / `↑` / `W` / `Ц`            |
| Двойной прыжок        | `Space` (в воздухе, если активен)    |
| Заряд ноты            | `Enter` (удерживать)                 |
| Выстрел нотой         | `Enter` (отпустить)                  |
| Меню арий             | Клик по певцу                        |
| Пауза                 | `P` или `Esc`                        |
| Продолжить            | `P` или `Esc`                        |
| Закрыть меню арий     | `Esc`                                |
| Пропустить диалог     | `Esc`                                |
| Следующая реплика     | `Space` / `Enter`                    |

**Курсор:** оружие наводится в сторону курсора мыши. Певец
разворачивается туда же, куда смотрит прицел.

## Типы голосов

| Голос    | Диапазон | Урон              | Особенность                        |
|----------|----------|-------------------|------------------------------------|
| Тенор    | C3 – C5  | Высокий, быстрый  | Лучший наверху, слабый внизу       |
| Бас      | E2 – E4  | Низкий, медленный | Мощный внизу, слабый наверху       |
| Баритон  | A2 – A4  | Средний           | Пик в середине диапазона           |

**Диапазон голоса определяет силу атаки:**
- Чем выше зарядка — тем **выше нота** и **сильнее удар** для тенора.
- Для баса — наоборот, **нижние ноты** бьют больнее.
- У баритона — пик в **середине диапазона**.

## Механика пения

### Зарядка ноты

1. Удерживайте `Enter` — нота «раскачивается» от низкой к высокой.
2. Отпустите `Enter` — певец «выстреливает» нотой в сторону курсора.
3. Чем точнее выбрана нота — тем выше урон.

### Кулдаун

После каждого выстрела — небольшая задержка (0.35 сек по умолчанию,
уменьшается прокачкой «Фразировка»).

### Формула урона

Где `t` — уровень зарядки от 0 до 1.

## Типы этапов

### 🎯 Collect (сбор нот)

Соберите нужное количество нот, разбросанных по уровню.

- **Одиночная нота** — 1 очко, +5 XP
- **Двойная нота** — 5 очков, +15 XP

### ⚔️ Kill (уничтожить врагов)

Победите N врагов определённого типа.

- Обычный враг — +40 XP
- Очки засчитываются сразу после смерти

### 👹 Boss (босс)

Сражение с уникальным боссом оперы. У каждого босса свои атаки
и цветовая схема.

## Система опыта

### Уровни

| Уровень | Требуется XP |
|---------|--------------|
| 1 → 2   | 100          |
| 2 → 3   | 150          |
| 3 → 4   | 200          |
| N → N+1 | 100 + (N−1)×50 |
| Макс.   | 10           |

### Начисление XP

| Действие                | XP     |
|-------------------------|--------|
| Обычный враг            | +40    |
| Одиночная нота          | +5     |
| Двойная нота            | +15    |

### Характеристики

За каждый уровень даётся **1 очко прокачки**. Открыть окно
характеристик — клик по плашке **«Ур. N»** внизу экрана.

| Характеристика       | Эффект                             | За очко |
|----------------------|------------------------------------|---------|

| **Дальность**        | Дистанция полёта ноты              | +10%    |

## Сохранение и загрузка

### Сохранение

1. Откройте паузу (`P` или `Esc`).
2. Нажмите **«Сохранить уровень»**.
3. Скачается файл `.song` с состоянием игры.

### Загрузка

1. Пауза → **«Загрузить уровень»**.
2. Выберите `.song`-файл.
3. Игра восстановит:
   - Текущую оперу и этап
   - Позицию игрока
   - HP, счёт, кулдауны
   - Живых врагов и их HP
   - Собираемые ноты
   - Уровень, XP, характеристики

## Советы

### Для новичков

- 🎯 **Цельтесь мышью** — курсор задаёт направление выстрела.
- ⚡ **Не держите заряд слишком долго** — внизу всегда быстро.
- 🏃 **Двигайтесь** — стоячего певца легко окружить.
- 💰 **Копите счёт** — арии стоят дорого, но спасают жизнь.

### Для опытных

- 🔥 **Комбинируйте арии:** Реквием + Ярость = мгновенная зачистка.
- 🧊 **Заморозка** отлично работает против толпы врагов.
- 🎵 **Двойные ноты** дают в 5 раз больше очков — за ними стоит
  охотиться.
- 👑 **На боссах** держитесь подальше и стреляйте в прыжке.
- 📈 **Вкачивайте «Дальность»** — она реально увеличивает шанс
  попасть по боссу с безопасного расстояния.

### Прокачка

**Оптимальный порядок для новичка:**
1. **Мощь голоса** (2 очка) — базовый урон
2. **Дальность** (2 очка) — безопасная дистанция
3. **Фразировка** (1 очко) — скорость атаки

**Для ветеранов:**
- **Исполнительность** до −30% — арии дешевеют
- **Артистизм** до +50% — эффекты длятся дольше

## FAQ

**Q: Игра не запускается / нет звука.**
A: Нажмите в любом месте экрана — браузер требует
взаимодействия пользователя для запуска аудиоконтекста.

**Q: Как получить арии?**
A: Они открыты сразу. Стоимость списывается из очков.

**Q: Что будет, если проиграть босса?**
A: На этапе босса — смерть → возврат на 1 этап назад
этой же оперы.

**Q: Что будет, если проиграть обычный этап?**
A: Возрождение на месте с полным HP и 2 сек. неуязвимости.

**Q: Как сбросить прогресс?**
A: Обновите страницу (F5). Прогресс сбрасывается,
если не загружен `.song`-файл.

**Q: Есть ли автосохранение?**
A: Нет. Только ручное через меню паузы.

**Q: Можно ли играть на телефоне?**
A: Да, но управление заточено под клавиатуру и мышь.
На телефоне играть неудобно.

**Q: Почему у меня не начисляются очки?**
A: Проверьте, что нота попала в цель. Промах не даёт очков.

**Q: Как посмотреть характеристики?**
A: Кликните на плашку **«Ур. N»** внизу экрана.
